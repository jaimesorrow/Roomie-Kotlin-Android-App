# Roomie

Minimal Android project skeleton initialized (Kotlin + Jetpack Compose + Material3).

Quick start

1. Open the project in Android Studio
2. Add your Firebase `google-services.json` to `app/google-services.json`
3. Sync Gradle
4. Build or run on an emulator/device

Commands

```bash
./gradlew assembleDebug
./gradlew test
```

Files added

- app/ module with MainActivity and a simple Compose Home screen
- Theme files and minimal resources
- google-services.json.example placeholder
- LICENSE (MIT)
- GitHub Actions workflow (build)
